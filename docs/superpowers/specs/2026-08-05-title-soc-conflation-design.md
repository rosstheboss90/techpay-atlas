# Title ↔ SOC Conflation Matrix — v2 Design Spec (pipeline draft)

**Date:** 2026-08-05 · **Status:** Draft for review — pipeline only

## Purpose

Role-similarity variant 2, "the novel one": show, data-driven, how a real job **title** gets
scattered across official **SOC** codes in the H-1B data — and how each SOC absorbs many different
titles. The title lens shows this for ~21 curated buckets (`socMix`); this generalizes it to a
frequency-ranked matrix over *normalized* free-text titles.

**Scope of this draft:** the **pipeline** only — normalize titles, aggregate the matrix, emit
`conflation.json`. It cannot be produced in the CI/dev sandbox (needs the raw H-1B files); the
emitted JSON is generated by a local `npm run pipeline`. The site UI is a follow-up (this spec fixes
the emitted contract so that work is unblocked).

## Decisions

1. **Normalize titles by stripping rank, not role.** `normalizeTitle` uppercases (already done at
   parse), drops parentheticals, punctuation, seniority/IC tokens (SENIOR/SR/JR/STAFF/PRINCIPAL/
   LEAD/ASSOCIATE/…) and trailing level/grade suffixes (roman numerals, `L4`, `LEVEL 3`, bare
   trailing digits), so `"SR. SOFTWARE ENGINEER II"` and `"STAFF SOFTWARE ENGINEER"` both collapse to
   `SOFTWARE ENGINEER`. Role-defining words (MANAGER, DIRECTOR, VP, HEAD, ARCHITECT) are kept. It's
   heuristic and imperfect by nature — conservative, documented, and unit-tested on the clear cases;
   tunable after seeing real output.
2. **Frequency-ranked, not exhaustive.** Emit the top `topTitles` (40) normalized titles by filing
   count (min `minFilings` 50 to avoid noise), each with its SOC distribution — top `topSocs` (6) by
   filings plus an aggregated `other`. Per-title we also emit `socCount` (distinct SOCs = the raw
   "conflation degree"). A full N×N title×SOC matrix is derivable client-side from this.
3. **Emit SOC codes, not labels.** The matrix spans all SOCs (incl. off-registry management/other
   codes with no label in our data). The site labels the 21 registry SOCs from `meta.roles` and
   shows the code for the rest — same idiom as the title-lens `socMix`.
4. **Additive + honest.** Purely additive to the pipeline (new `conflation.json`; existing outputs
   byte-identical bar `meta.generated`). A tripwire guards that normalization didn't collapse or
   over-shatter the title space.

## Architecture

| File | Change |
|---|---|
| `pipeline/lib/normalize-title.ts` | NEW — `normalizeTitle(raw): string` (pure) |
| `pipeline/lib/aggregate-conflation.ts` | NEW — `aggregateConflation(records, opts)` → matrix (pure) |
| `pipeline/lib/emit.ts` | `buildConflation(agg, lcaPeriod)` + `ConflationJson` type |
| `pipeline/run.ts` | compute from `matched` (all-SOC stream), assert tripwire, emit `conflation.json`, report line |
| `pipeline/config.ts` | `THRESHOLDS.minConflationTitles` (20) |
| `pipeline/tests/*` | unit tests for normalize + aggregate (run in CI, no raw data needed) |

Input is the same deduped, CBSA-matched, all-SOC `matched` stream the title lens uses — each record
carries `title` + `soc`.

## Emitted contract (`site/public/data/conflation.json`, committed after a local regen)

```jsonc
{
  "lcaPeriod": "FY2025 Q1–Q4",
  "totalFilings": 312845,          // filings under the selected titles
  "distinctTitles": 41230,         // distinct normalized titles seen (pre-top-N)
  "titles": [
    { "title": "SOFTWARE ENGINEER", "filings": 40213, "socCount": 9,
      "socs": [ { "soc": "15-1252", "filings": 31980, "share": 0.795 },
                { "soc": "15-1211", "filings": 3120, "share": 0.078 },
                { "soc": "other", "filings": 900, "share": 0.022 } ] }
  ]
}
```

## Error handling

| Condition | Handling |
|---|---|
| Title normalizes to empty | record skipped |
| Title below `minFilings` | excluded from the emit (noise floor) |
| Fewer than `minConflationTitles` survive | pipeline **fails loudly** (normalization likely broke) |
| Off-registry SOC | emitted as its raw code; labeled `other` only when beyond `topSocs` |

## Testing

- `normalize-title.test.ts`: strips seniority + level suffixes; variants merge to one canonical;
  keeps role words; empties safely; idempotent.
- `aggregate-conflation.test.ts`: top-N by filings; per-title SOC shares sum to 1; `socCount` and
  the `other` bucket; `minFilings` floor; normalization merges variants before counting.

(Both are pure — they run in the CI pipeline job without raw inputs. `run.ts`'s emit path is
exercised only by a live `npm run pipeline`.)

## Out of scope

- The **site UI** (a title×SOC matrix/heatmap) — a follow-up once `conflation.json` is regenerated.
- SOC→label lookup for off-registry codes; reverse (SOC→titles) index (derivable client-side).
- Any change to existing emitted files.
